### 🧭 My DBA Framework

I organize DBA work into nine domains. Each domain gets four kinds of material:
**Scripts** (detect) · **Runbooks** (respond) · **Checklists** (prevent) · **Case studies** (learn).

| # | Domain | Key question | Status |
|---|---|---|---|
| 01 | Availability & DR | Can we recover, and within RPO / RTO? | 🟡 Scripts in testing |
| 02 | Performance | What is slow, and why? | 🟡 Scripts in testing |
| 03 | Monitoring & Health | Is the server healthy right now? | 🟡 Scripts in testing |
| 04 | Maintenance | Indexes, statistics, integrity checks | 🟡 Scripts in testing |
| 05 | Security & Compliance | Who can do what, and is it audited? | 🟡 Scripts in testing |
| 06 | Change Management & Database-as-Code | How do schema changes ship safely? | ⚪ Planned |
| 07 | Capacity & Cost | When do we run out, and what does it cost? | ⚪ Planned |
| 08 | Incident Response | What do we do in the first 15 minutes? | 🟡 Scripts in testing |
| 09 | Automation & AI | What should no longer be done by hand? | ⚪ Planned |
